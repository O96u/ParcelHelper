# ParcelHelper v1.2.0 · v1.2.x 系列首发

## 新增
- WidgetKit 小 / 中 / 大主屏幕组件，与主 App 通过 App Group 共享待取件快照。
- App 内检查 GitHub Releases、展示中文更新说明，并支持将 IPA 交给签名工具安装。
- 首页身份码快捷入口、快递鸟网页登录后尝试自动导入 API 密钥等体验增强。

## 修改
- CI 改为**仅推送 `v*` 标签**时构建发版；构建摘要与 Release 说明统一为中文。
- 使用 Xcode 26 / iOS 26 SDK 构建，启用 Liquid Glass 导航栏等新系统视觉效果。
- 拼多多网页授权默认关闭，并补充与会话互斥相关的说明与警告。

## 修复
- 平台授权与拼多多订单同步、小米等账号流程的多项稳定性调整（详见 v1.2.0 之前的提交记录）。

## 安装说明
- Release 中的 `ParcelHelper.ipa` 为**未签名**构建产物，须使用有效证书签名后再安装。
- 主 App 与小组件扩展须各自使用包含相同 **App Group** 的描述文件签名；可在仓库变量 `PH_WIDGET_GROUP` 中配置与证书一致的组 ID。
- 第三方重签名可能影响实时活动、主屏幕组件、通知或快捷指令。
