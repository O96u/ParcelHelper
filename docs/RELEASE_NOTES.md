# ParcelHelper v1.0.0 · 首个正式版

## 新增
- 原生 SwiftUI 包裹管理、驿站管理、运单搜索、取件统计与物流轨迹视图。
- 淘宝、京东、菜鸟、拼多多、丰巢、小米等已授权平台的数据读取与同步入口。
- 短信与剪贴板识别、快捷指令动作、物流变化本地通知、锁屏实时活动和灵动岛功能。
- GNU GPL-3.0 开源许可证及项目文档。

## 修改
- 将应用与安装包命名统一为 **ParcelHelper**，项目介绍统一为 **ParcelHelper for iOS**。
- 刷新频率与实际前台同步逻辑保持一致，移除无效的小组件刷新设置。
- GitHub Actions 使用 Swift 和 Xcode 构建，发布文件统一为 `ParcelHelper.ipa`。
- 从这一版开始，发布说明按「新增 / 修改 / 修复」分类记录。

## 修复
- 修正物流「已签收」「待取件」与「用户已取件」的状态识别。
- 调整物流轨迹时间线连接、取件趋势布局、授权解除确认弹窗和包裹搜索入口。
- 修复此前快捷指令构建语法问题，完善平台同步状态保存。

## 安装说明
- Release 中的 `ParcelHelper.ipa` **仍是未签名的构建产物**，文件名不再包含 unsigned。
- 在 iPhone 上安装前需要使用有效证书签名。第三方重签名可能影响实时活动、系统通知或快捷指令注册。
- 平台数据读取依赖用户授权和平台接口，无法保证所有订单持续可读取；不提供云端实时推送。
